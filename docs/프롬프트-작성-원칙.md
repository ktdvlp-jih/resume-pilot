# 프롬프트 작성 원칙 (다사용자)

관리자 Prompt 편집·Flyway 추가 시 적용한다. 특정 사용자 이력에 맞춘 예시·금지어를 넣지 않는다.

## 해야 할 것

- 사실 출처: 경험 RAG·공고 분석·선택한 입력만
- 역할·직군·시점은 **입력에 적힌 표현·기간만** (없으면 단정·라벨 부착 금지)
- 문항 중복은 “같은 국면 반복 금지” + 파이프라인 경험 할당으로 처리
- 제품 UX로 유지: 지원동기·포부 등에서 **AI 코딩 도구 제품명(Claude/Cursor 등) 나열 금지**, 직무역량에서만 주요 소재 허용

## 하지 말 것

- 특정 도메인·제품·회사·프로젝트명을 규칙/예시로 박기
- 특정 직군·고용 형태 라벨을 프롬프트에 예시로 넣기
- 금지 목록을 한 사용자의 키워드 카탈로그로 만들기

## 변경 경로

- 공통 규칙: `prompt_versions` (Flyway `resume-api`만)
- 구조 강제(할당·컨텍스트): `resume-ai` / `rag-service`
- 하드코딩 슬롯에 도메인 고유명을 다시 넣지 말 것
