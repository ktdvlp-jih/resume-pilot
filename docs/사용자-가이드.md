# ResumePilot 사용자 가이드

> 대상: 일반 사용자 (web)
> 기준: 2026-07-08 배포 상태

## 1) 시작하기

1. 서비스 접속 후 회원가입/로그인
2. 가입 직후 **1분 시작(`/onboarding`)** — 공고 URL을 붙여 넣고 분석을 시작합니다 (Free 월 체험 지급)
3. (선택) 경험 직접 추가 또는 `/experiences/import`에서 Notion·GitHub 초안 가져오기
4. 워크스페이스에서 자소서 생성

좌측 메뉴: `경험 라이브러리 → 채용공고 → 워크스페이스` 순도 가능합니다.

## 2) 경험 라이브러리 작성

핵심 원칙은 **구체성**입니다.

- 제목: 프로젝트/업무명을 명확히 작성
- 설명: 무엇을 만들었는지, 어떤 문제를 해결했는지 작성
- 역할: 본인의 책임 범위를 구체적으로 작성
- 결과: 수치(%, 시간, 비용, 건수) 중심으로 작성

권장: 2~5개 경험을 먼저 등록하면 RAG 추천 정확도가 올라갑니다.

Notion Internal Integration 토큰 또는 GitHub PAT로 `/experiences/import`에서 **초안**을 가져온 뒤, 사실관계를 확인·수정하고 확정하세요. AI는 없는 수치를 지어내지 않습니다.

## 3) 채용공고 업로드/분석

`채용공고` 메뉴에서 3가지 방식 지원:

- 텍스트 붙여넣기
- URL 입력
- 파일 업로드(PDF/PNG/JPG 등)

분석 완료 후 확인할 항목:

- 회사명/포지션
- 필수/우대 기술
- 기술 키워드
- 핵심 역량

주의: 이미지 공고는 OCR 품질에 따라 회사명 인식이 다를 수 있습니다. (저해상도면 텍스트/URL 업로드 권장)

## 4) 워크스페이스에서 자소서 생성

1. 채용공고 선택 또는 공고 텍스트 입력
2. `관련 경험 추천` 실행
3. Rewrite 레벨(0~100) 조절
4. `자기소개서 생성` 실행

결과 패널에서 확인:

- 추천 경험(RAG)
- 품질 점수
- 키워드 매칭/누락
- AI 흔적 탐지
- 첨삭/예상 면접 질문

AI 생성·첨삭·공고 분석 등은 **토큰 또는 기능별 횟수**가 필요합니다. 부족하면 `/billing`에서 충전하세요. 횟수 팩이 있으면 해당 기능은 횟수를 먼저 쓰고, 없으면 고정 토큰 단가가 차감됩니다.

## 4-1) 충전·결제

1. 좌측 메뉴 `충전·잔액` 또는 `/pricing`에서 상품 확인
2. 로그인 후 구매 → 토스 결제창 (카드)
3. 성공 시 `/billing/complete`에서 서버가 승인·지급 (새로고침해도 이중 지급되지 않음)
4. 실패 시 `/billing/fail` — 승인을 호출하지 않음

헤더에 토큰 잔액이 표시됩니다. 관리자가 토스 키를 등록하기 전에는 결제창이 열리지 않습니다.

관리자·운영 상세: [결제-과금-가이드.md](결제-과금-가이드.md)

## 5) 품질 높이는 팁

- 경험의 결과를 수치화할수록 생성 품질이 올라갑니다.
- 공고 원문의 필수 기술을 누락 없이 입력하세요.
- 생성 결과는 초안으로 보고, 본인 경험 사실관계 검토 후 확정하세요.

## 6) 자주 묻는 문제

- **추천 경험이 비어 있음**: 경험이 너무 적거나 키워드가 약함 → 경험 2개 이상 보강
- **AI 생성 실패**: 잔액 부족이면 `/billing`에서 충전. 그 외에는 잠시 후 재시도, 공고 텍스트 길이 축소, 네트워크 상태 확인  
  (운영에서는 다중 Provider failover가 자동 적용되지만, 모든 Provider 한도 소진 시 실패할 수 있음)
- **분석 품질이 낮음(이미지 공고)**: 해상도 높은 이미지 또는 텍스트/URL 방식 권장

## 7) 개인정보/보안 주의

- 이력서 원문/민감정보는 필요 최소한만 입력
- 비밀번호 재사용 금지
- 공용 PC 사용 후 반드시 로그아웃

## 8) 추천 사용 순서 (10분 온보딩)

1. 경험 2~3개 등록 (3분)
2. 채용공고 업로드/분석 (2분)
3. 워크스페이스 추천+생성 (3분)
4. 탐지/첨삭 반영 후 저장 (2분)
