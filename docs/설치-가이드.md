## Part 1 — 개요

| 환경 | 방식 | 포트 |
|------|------|------|
| **로컬 개발** | 터미널 (DB만 Docker 가능) | API 8080, Vite 5173/5174 |

## Part 2 — 개발 PC (터미널)

```bash
# macOS
cp .env.example .env.local
source ./scripts/load-env-local.sh
```

```powershell
# Windows
.\scripts\resume-pilot.ps1 setup    # 1회
.\scripts\resume-pilot.ps1 db       # 로컬 PostgreSQL Docker
copy .env.example .env.local
# JWT_SECRET, DEPLOY_HOST 등 설정. LLM 키는 Admin /admin/llm-settings
```

## Part 3 — Ubuntu 서버 {#part-3-ubuntu-서버}

### 3-1. 로컬 `.env`에 배포 대상 설정 (Git 제외)

로컬 PC의 `.env`에만 추가 (`.env.example` 참고):

```env
DEPLOY_HOST=jeon@your-lan-host
LAN_HOST=your-lan-host
APP_PORT=9180
```

| 변수 | 설명 |
|------|------|
| `DEPLOY_HOST` | SSH 대상 (`user@host`) |
| `LAN_HOST` | 브라우저·CORS용 호스트명/IP (서버 `.env`의 `LAN_HOST`와 동일 권장) |
| `APP_PORT` | ResumePilot 공개 포트 (기본 `9180`) |

### 3-2. 서버 사전 준비 (1회)

```bash
sudo apt update
sudo apt install -y docker.io docker-compose-v2
sudo usermod -aG docker $USER
# 재로그인 후
docker compose version
```

배포 경로: `~/apps/resume-pilot`

### 3-3. Windows에서 원격 배포

```powershell
cd e:\workspace\resume-pilot
# .env 에 DEPLOY_HOST 설정 후
.\scripts\deploy-remote.ps1
```

Linux/macOS:

```bash
export DEPLOY_HOST=jeon@your-lan-host
./scripts/deploy-remote.sh
```

### 3-4. 서버 `.env` (프로덕션)

```bash
cd ~/apps/resume-pilot
cp .env.production.example .env
nano .env   # POSTGRES_PASSWORD, JWT_SECRET, LAN_HOST (LLM 키는 Admin /admin/llm-settings)
./scripts/server-up.sh
```

### 3-5. Ubuntu 서버에서 배포 (git pull)

```bash
cd ~/apps/resume-pilot
chmod +x scripts/resume-pilot.sh
./scripts/resume-pilot.sh deploy
```

또는 `./scripts/server-up.sh` (최초 `.env` 생성 포함).

### 3-6. 배포 후 확인 (서버)

```bash
cd ~/apps/resume-pilot
docker compose ps
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:${APP_PORT:-9180}/
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:${APP_PORT:-9180}/admin/
```

브라우저 (LAN): `http://<LAN_HOST>:<APP_PORT>/`

### 3-7. `.env` 서버로 복사

`deploy-remote`는 `.env`를 업로드하지 않습니다.

```powershell
scp .env ${env:DEPLOY_HOST}:~/apps/resume-pilot/.env
```

### 3-8. 공개 HTTPS (호스트 nginx)

origin **1개**:

```text
http://127.0.0.1:9180
```

`/`, `/admin/`, `/api/v1` 모두 동일 포트. 사이트 설정 예시: [`scripts/nginx-resume.ggury.com.conf`](../scripts/nginx-resume.ggury.com.conf)

AI 생성·탐지·첨삭은 60초를 넘길 수 있으므로 `proxy_read_timeout` / `proxy_send_timeout`은 **300s**.

적용:

```bash
sudo cp scripts/nginx-resume.ggury.com.conf /etc/nginx/sites-available/resume.ggury.com
sudo nginx -t && sudo systemctl reload nginx
```

동일 서버 포트 격리: [서버-공존-가이드.md](서버-공존-가이드.md)

## Part 4 — PC 전환 {#part-4-pc-전환}

SpecStory(`.specstory/`)는 **로컬 전용**입니다. Git에 커밋하지 않습니다.

```powershell
git pull
# 작업 후 (.specstory 는 add 하지 않음)
git add .cursor .claude
git commit -m "feat: …"
git push
```

Cursor: `/handoff` 또는 `@.specstory/history/` 최신 파일(로컬).

## Part 6 — 환경 변수 파일

| 파일 | 위치 | Git |
|------|------|-----|
| `.env.example` | 로컬 터미널 개발 예시 | ✅ |
| `.env.production.example` | 서버 Docker 예시 | ✅ |
| `.env.local` | 로컬 개발 실제 값 (`load-env-local.ps1`로 세션 로드) | ❌ |
| `.env` | AI 서비스별 시드 + 배포용 실제 값 (`DEPLOY_HOST`, `LAN_HOST` 포함) | ❌ |

서버 URL 예시 (플레이스홀더):

```text
http://<LAN_HOST>:<APP_PORT>/
http://<LAN_HOST>:<APP_PORT>/admin/
http://<LAN_HOST>:<APP_PORT>/api/v1
```
