# ResumePilot 연동 설정 가이드

Admin `/admin/integration-settings`에서 관리하는 외부 연동 키·토글 운영 문서다.  
OAuth·결제·메일·자격 종목 조회 키는 **여기(DB)를 우선**하고, `.env`는 값이 비어 있을 때만 폴백한다.

관련: [관리자-가이드.md](관리자-가이드.md), [결제-과금-가이드.md](결제-과금-가이드.md), [실행-가이드.md](실행-가이드.md), [API-규약.md](API-규약.md)

---

## 1. 원칙

| 항목 | 규칙 |
|------|------|
| 저장소 | `integration_configs` 테이블 (시크릿은 AES-GCM, `LLM_ENCRYPTION_KEY`) |
| 우선순위 | **Admin(DB) > `.env` / 환경변수** |
| UI | `resume-admin` → 연동 설정. 시크릿은 마스킹, 「눈」아이콘으로 일시 조회 |
| `.env`에 두지 말 것 | OAuth Client Secret, Resend API Key, Q-Net 서비스 키 (운영은 Admin 권장) |
| `.env`에 둘 것 | `JWT_SECRET`, `INTERNAL_API_TOKEN`, `LLM_ENCRYPTION_KEY`, DB 비밀번호 |

로컬 URL: `http://localhost:5174/admin/integration-settings`  
운영: `{PUBLIC_WEB_URL}/admin/integration-settings`

## 2. 화면 구성

| 섹션 | 용도 | 주요 키 |
|------|------|---------|
| PG · 토스페이먼츠 | 결제 | `TOSS_PAYMENTS_CLIENT_KEY`, `TOSS_PAYMENTS_SECRET_KEY` |
| 경험 가져오기 | Notion / GitHub OAuth | `*_CLIENT_ID`, `*_CLIENT_SECRET`, `*_OAUTH_REDIRECT_URI` |
| SNS 로그인 | Google / 카카오 | Google 3키 + 카카오 3키 + **로그인 화면 표시** |
| 자격 종목 조회 · Q-Net | 국가자격 종목 목록 API | `QNET_LOOKUP_ENABLED`, `QNET_SERVICE_KEY` |
| 메일 발송 | 가입 인증·계정 연결 | `MAIL_PROVIDER`, `MAIL_FROM`, `RESEND_API_KEY` |

### Select 필드 (텍스트 입력 아님)

| 키 | 옵션 | 기본(미저장 시) |
|----|------|-----------------|
| `KAKAO_OAUTH_ENABLED` | 숨김 / 표시 | 숨김 (`false`) |
| `QNET_LOOKUP_ENABLED` | 사용 안 함 / 사용 | 사용 안 함 |
| `MAIL_PROVIDER` | 로그(개발용) / Resend | `log` |

## 3. SNS 로그인 (Google / 카카오)

### Google

1. Google Cloud Console에서 OAuth 클라이언트 생성.
2. Redirect URI: Admin 도움말(○)의 「현재 API 기준」 URL을 등록.  
   로컬 예: `http://localhost:8080/api/v1/auth/oauth/google/callback`
3. Admin에 Client ID / Secret / (선택) Redirect URI 저장.
4. 사용자 `/login`·`/signup`에 Google 버튼이 나타남.

### 약관·개인정보 동의 (소셜)

| 화면 | 동작 |
|------|------|
| `/signup` | 이메일 가입·소셜 버튼 모두 동의 필수 |
| `/login` | 이메일 로그인은 동의 불필요. **소셜 버튼 직전에** 이용약관·개인정보처리방침 동의 후 진행 |

- 프론트: 미동의 시 소셜 시작 차단 + 동의 여부를 OAuth `state`에 담아 API로 전달
- 서버: **신규 SNS 계정 생성** 시에만 `termsAccepted`+`privacyAccepted`가 true인지 검증. 이미 있는 계정 로그인은 동의 재검증 없이 토큰 발급
- 동의 없이 신규 생성을 시도하면 「서비스 이용약관과 개인정보처리방침에 동의해 주세요」로 콜백 실패

### 카카오

1. 카카오 개발자 콘솔에서 앱·Redirect URI 등록 (Google과 동일 패턴, `/kakao/callback`).
2. **비즈 앱 + 이메일 권한**이 있어야 가입·연동이 안정적이다. 권한 전에는 버튼을 켜지 말 것.
3. Admin에서 Client ID / Secret 저장 후 **「로그인 화면 표시」→ 표시**로 저장.
4. 기본은 숨김. 코드는 유지하되 UI만 끈다.

동일 이메일의 SNS↔이메일 계정 연결은 비밀번호 확인 또는 메일 링크(`POST /oauth/link`, `POST /oauth/link/send-email`).

## 4. Q-Net 자격 종목 조회

공공데이터포털 [국가자격 종목 목록](https://www.data.go.kr/data/15003024/openapi.do) OpenAPI.

1. data.go.kr에서 활용신청 후 **서비스 키** 발급.
2. Admin → **자격 종목 조회 · Q-Net**
   - 종목 조회 사용: **사용**
   - 서비스 키: 발급 키 저장
3. 사용자 포트폴리오 자격 입력 시 종목명 매칭·메타 보강에 사용. (개인 취득 여부 검증 API는 공개되지 않음)

폴백: `.env`의 `QNET_LOOKUP_ENABLED`, `QNET_SERVICE_KEY` (Admin 비어 있을 때만).

코드: `CertificationLookupService` — DB `getPlain` 후 env.

## 5. 메일 발송

| `MAIL_PROVIDER` | 동작 |
|-----------------|------|
| `log` | API 로그에 `[mail:log] … url=` 출력. 로컬 개발용 |
| `resend` | [Resend](https://resend.com)로 실제 메일. API 키·보내는 주소 필요 |

설정 순서:

1. Resend에서 API 키·도메인(또는 `onboarding@resend.dev` 테스트) 준비.
2. Admin → **메일 발송**
   - 발송 방식: Resend
   - 보내는 주소: 인증된 From
   - Resend API 키: 저장
3. API 재기동 없이 다음 발송부터 반영 (호출 시마다 DB 조회).

폴백: `.env` `MAIL_PROVIDER`, `MAIL_FROM`, `RESEND_API_KEY`.

코드: `MailService` — Admin 우선.

가입 시 `AUTH_EMAIL_VERIFICATION_BYPASS=true`는 **로컬만**. 운영 금지.

## 6. 키 우선순위 · 코드 위치

```
요청 시
  └─ IntegrationSettingsService.getPlain(KEY)
       ├─ DB에 값 있음 → 복호화 후 사용
       └─ 없음/빈값 → @Value / 환경변수 폴백
```

| 영역 | 서비스 | 상수 접두 |
|------|--------|-----------|
| 공통 레지스트리 | `IntegrationSettingsService` | `KNOWN_KEYS` / `SECRET_KEYS` |
| SNS | `SocialOAuthService` | `GOOGLE_OAUTH_*`, `KAKAO_OAUTH_*` |
| Q-Net | `CertificationLookupService` | `QNET_*` |
| 메일 | `MailService` | `MAIL_*`, `RESEND_API_KEY` |
| 결제 | 결제 서비스 | `TOSS_PAYMENTS_*` |

마이그레이션 예:

- `V87__sns_oauth_integration_configs.sql` — SNS
- `V89__qnet_mail_integration_configs.sql` — Q-Net · Mail

Admin UI: `resume-admin/src/pages/IntegrationSettingsPage.tsx`  
i18n: `resume-admin/src/i18n/locales/ko.json` · `en.json` (`integrationSettings.*`)

## 7. 새 연동 키 추가 절차

1. Flyway `Vxx__….sql` — `integration_configs`에 `INSERT … ON CONFLICT DO NOTHING` (`is_secret` 컬럼명 주의).
2. `IntegrationSettingsService` — 상수, `KNOWN_KEYS`, 시크릿이면 `SECRET_KEYS`, `categoryFor`.
3. 소비 서비스에서 `getPlain` + env 폴백.
4. Admin `IntegrationSettingsPage` — `ProviderDef` / `FIELD_LABEL_KEYS` / 필요 시 `SELECT_OPTIONS`.
5. ko/en i18n.
6. `IntegrationSettingsServiceTest`의 `listForAdmin` `hasSize` 갱신.
7. `.env.example` / `.env.production.example`에 「Admin 권장」 주석만 (실값 금지).

## 8. 운영 체크리스트

- [ ] 시크릿이 UI에서 마스킹되는가
- [ ] 마스크 상태로 저장해도 기존 시크릿이 덮이지 않는가
- [ ] Redirect URI가 OAuth 콘솔과 일치하는가 (도움말 URL 복사)
- [ ] 카카오: 이메일 권한 전 「표시」를 켜지 않았는가
- [ ] Q-Net: 사용 + 서비스 키 둘 다 있어야 조회 동작
- [ ] 메일: Resend인데 키가 비면 `log`처럼 동작(실메일 미발송) — 키·방식을 함께 확인
- [ ] `INTERNAL_API_TOKEN` / `JWT_SECRET` / `LLM_ENCRYPTION_KEY`는 여전히 서버 `.env`만

## 9. 장애 빠른 확인

| 증상 | 확인 |
|------|------|
| SNS 버튼 없음 | Google 키 미등록 / 카카오는 「숨김」 |
| OAuth redirect 오류 | Admin 도움말 URL vs 콘솔 등록 URI |
| 인증 메일이 안 옴 | `MAIL_PROVIDER`·Resend 키·From / 로그 모드면 API 로그의 url |
| 자격 종목 검색 불가 | Q-Net 「사용」+ 서비스 키 / 공공 API 장애 |
| 저장 후 반영 안 됨 | API가 같은 DB를 보는지 / Admin이 빈 값으로 지웠는지(빈 값이면 env 폴백) |
