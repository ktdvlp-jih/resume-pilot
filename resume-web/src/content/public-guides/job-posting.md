# 채용 공고 올리는 법

로그인 후 `/job-postings`에서 공고를 가져옵니다. 사람인·잡코리아 URL, 텍스트 붙여넣기, PDF·이미지(OCR)를 지원합니다. 이미지 인식이 나쁘면 텍스트나 URL을 쓰세요.

## 넣을 것

담당 업무, 자격, 우대, 근무조건, 복지, 인재상처럼 **있는 섹션만** 넣습니다. 지원 버튼·개인정보 안내는 빼도 됩니다.

## 제목

텍스트·이미지로 가져올 때는 제목을 먼저 적습니다. 예: 「웹 백엔드 개발」.

## 공통 공고

본인 공고를 공통으로 공개하면 다른 로그인한 사용자가 그 공고로 작성할 수 있습니다. 공개 캘린더(`/calendar`)에는 제목·기업·마감일만 나갑니다. 공고 원문은 나가지 않습니다.

## 생성과의 관계

공고 분석은 키워드·역량을 뽑습니다. 경험 라이브러리에 없는 우대 기술은 자소서에 넣지 마세요. 근거가 없으면 「내용이 부족하여 생성하지 않음」이 정상입니다.
